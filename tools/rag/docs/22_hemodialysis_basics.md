# 血液透析那些事

## 一、什么是血液透析呢？

血液透析，是一种替代肾脏功能的医疗手段。当人的肾脏功能衰竭到“终末期肾病”也就是“尿毒症”时，无法有效清除血液中的代谢废物和多余水分，就需要通过血液透析来人工完成这项工作，以维持身体内环境的稳定和生命，您可以把它想象成一个外部的、人工的“过滤器”，替代肾脏工作。

## 二、为什么要血液透析呢？

当肾脏功能只剩下正常功能的10%-15%以下，会导致：
恶心、呕吐、食欲不振，身体浮肿、气急，乏力、贫血，电解质紊乱，甚至严重时的高钾血症可导致心脏骤停，这时就必须通过透析或肾移植来维持生命。

## 三、血液透析是如何工作的？

1. 建立血管通路：首先需要建立一个能将血液持续引出身体并输回的通路。
2. 血液引出：透析开始时，用两根针穿刺血管通路。一根针将血液从身体引出，通过管路流入透析器。
3. 在透析器内净化：透析器内部有成千上万根极细的中空纤维管，纤维管壁是半透膜，像非常精细的筛网。患者的血液在纤维管内部流动，而管外流动着与血液成分浓度不同的透析液。
根据浓度差原理，血液中的小分子废物如尿素、肌酐和多余电解质会透过半透膜上的小孔，移动到透析液中，从而被清除。
同时，根据压力差原理，血液中多余的水分会被“压”到透析液侧，从而被排出体外。净化后的血液则从透析器另一端流出。
4.血液回输：净化后的血液通过另一条管路和另一根针，安全地返回患者体内。通常每周需要进行2-3次，每次持续约4小时。需要在医院透析中心进行。

## 四、血液透析常用治疗模式：

1.血液透析：主要清除小分子毒素：尿素、尿酸、肌酐、电解质等，以及过多的水分。
2.血液透析滤过：血液透析滤过是一般常说的血滤，清除血液中的大中小分子毒素，达到更好的透析效果。
3.血液透析+灌流：通过灌流器中的吸附剂，能够有效地吸附清除体内中、大分子（β2微球蛋白）毒素，尤其是脂溶性毒素。
