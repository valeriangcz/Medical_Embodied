# 控水小技巧

每周透析三次者，每日饮水量等于500毫升加前一天的尿量
每周透析两次者，每日饮水量等于300毫升加前一天的尿量

## 饮食中水的估算方法：

粥含水：百分之90；豆腐和各种新鲜蔬菜含水：百分之90；
水果类含水：百分之90
新鲜肉类、蛋类、鱼虾类：百分之80
冰淇淋和酸奶：含水百分之 80
米饭、红薯、山药、土豆等：百分之70
各种熟食（酱肉、烤鸭、肉串、炸鸡等）：百分之50
馒头、饼、面条、面包：百分之30
粉丝、腐竹、干货（豆、菇、木耳等）：百分之10
点心类（饼干、蛋糕、糖、巧克力等）：百分之10
控水技巧：稍有口渴时可用棉花棒湿润口唇，口渴时可含加了柠檬汁的冰块，不喝或少喝浓茶、咖啡，少食用含水量高的食物，如西瓜等，可咀嚼口香糖、柠檬片，先将一天要喝的水量装好再平均分配饮用养成小口喝水，不一饮而尽的习惯
，含花旗参片以代替开水，不吃或少吃高盐食物，如酱菜、咸菜、熏肉等，请记住日常吃进去的茶、啤酒、米饭、青菜、 水果及菜汤等均含有较多水份，进食时应考虑其中 所含的水分。
