# 限制钠饮食

所有患者应坚持限盐饮食，每日摄入1.5到2.0克的钠元素，或者3到5克的食盐，避免加工类食品，如腌制品，罐头等
一些调味品也不可忽视，5克酱油所含的盐分相当于1克盐，20克豆瓣酱所含的盐分相当于1克盐，可以用白醋、柠檬、花椒、五香、八角、香菜、葱、蒜、姜等来替换一些含盐调味料。
控盐小技巧：1.计量汤匙法：一定养成使用计量汤匙习惯，按标推使用盐和其它调味品。
2.餐时加盐法：烹调时不放盐，食用时把少量盐、酱油等撒在食物表面，使舌上味蕾受较强刺激，既唤起食欲，又减少盐的摄入量。
3.一菜加盐法：一餐几个菜时，可将盐集中在一种菜上，其它的菜肴尽量不用盐 。与其所有饭菜都淡，不如使一种菜突出，更容易食用。
量化用盐，每天摄入不超过5克盐
摄入太多盐不仅会使血压升高，还会导致体内水钠潴留，增加肾脏负担，进而加重肾脏疾病病情。
建议透析肾友每天食盐摄入量不超过3克。小技巧：1个普通啤酒瓶盖的食盐重量约为5克。
少吃加工食品，购买包装食品前应注意看包装上标注的营养成分表。
