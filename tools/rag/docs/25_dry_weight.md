# 您的“干体重”事关重大

## 一、干体重究竟是怎么回事呢？为什么要设定干体重，要怎么进行评估？

每次透析治疗均根据干体重制定超滤量，使透析后达到或接近干体重。
如果透析后未达到干体重，每次透后体重均有增加，透析间期又不能很好控制饮水量，患者就有可能出现心衰、高血压等并发症。
反之如透后体重低于干体重，患者就会出现低血压、呕吐、肌肉痉挛、透析后虚弱无力等，严重影响身体健康及生活质量。
透析患者的干体重会有变化，透析后随着患者食欲改善、营养及摄入的热量增加，干体重会逐渐增加。反之如食欲下降、肌肉减少、出现营养不良，干体重也会下降。因此透析时应定期修正干体重。
透析患者在家中应经常测量体重，并自我控制水分的摄入。两次透析之间体重最好不超过干体重的5％，年纪大的人心脏功能下降，体重增加量要更低些,65岁以上老年人约为干体重的2.5%.

### 如何自我判断干体重是合适的？

1.根据症状：自觉舒适，一般行走应无气短、呼吸困难，无夜间阵发性的呼吸困难；面部无浮肿，血液透析后血压基本正常。
2.根据血压：合适的血压，如果平时血压较高些，透析后半段血压平稳下降至能承受范围，每个人不同。如果平时血压就低，保持稳定就行。
3.根据是否有肌肉痉挛：也就是抽筋，抽筋分两种一种小发作，能感受到但不疼痛只是肌肉的小震颤；一种大发作疼痛难忍。先是小发作，不要等到大发作，这时就正好血压和抽筋是判断干体重的因素，要在透析液钠合适时才正确出现。
4.根据体重：透析间隔体重增长3-5%比较合适，其中1.5-2%在血管中其余都在组织细胞中。
每个人根据个人情况总结一些特征，比如根据上眼皮的肿胀程度判断，自己用手摸一下或者拿镜子看看；手指的肿胀程度，如果戴戒指就更容易感觉；抽筋的部位，小腿、腹部、脖子、下巴分别判断。
若脱水过多时，患者可出现疲乏、口渴、头晕、肌肉抽搐、皮肤干燥、声音嘶哑，喉头干燥，耳鸣耳聋，眼眶凹陷、直立性低血压甚至休克的症状。

## 水分摄入的控制原则：

### 每周血液透析３次者：500ml／日＋前一天的尿量

### 每周血液透析２次者：300ml／日＋前一天的尿量

## 三、透析患者水分管理技巧：

每天三测，心中有数：测尿量，测量出入水量（饮水＋服药用水输液量），测体重（同一时间、同秤、同地点、每日早晚后评估水分是否摄入过多）；
固定茶杯，平均分配：利用计量杯，预先测量好自己常用的茶杯、玻璃杯、将一日可饮水用量固定容器装好，平均分配到一天中；
食物水分，分清多少：不要过量摄取含水分多的食物：如茶、啤酒、茶汤、果汁、多汁水果、多汁蔬菜、豆腐、牛奶等，要控制这些含水多的饭菜：汤、炖过的菜、面条等；

### 清淡少盐，减少口渴：钠盐的摄入是引起口渴的主要原因，必须坚持清淡饮食；

冰块糖果，缓解口渴：①把水果汁、牛奶冻成冰块，口渴时含在口中，让冰慢慢熔化，化了就吐掉；②含不太甜的硬果，嚼口香糖，或挤一点柠檬汁在嘴中，减少口渴；③稍微口渴时，用棉花棒湿润嘴唇或漱口，十分渴时才小心喝水
适量运动，增加出汗：试看做轻度运动或找事做，尽可能使身体保持活动状态，促进排汗，减少想喝水的感觉，心脏不好的人要控制出汗。
