# 透析日患者注意事项

## 透析前准备：

1.合理饮食，避免空腹透析，避免透析中低血糖的发生 。
2.带好必备物品及相关药品。
3.留置静脉导管进行透析的肾友，注意保持局部清洁干燥，建议穿衣领宽松，最好是开衫或领口装拉链，方便置管换药及使用。
4.用内瘘进行透析的肾友，做好内瘘侧肢体清洁，每次透析前用肥皂清洗穿刺部位皮肤，衣袖宽松， 方便卷起。冬天最好袖子装拉链或穿棉背心。
5.准确测量体重，防止脱水过多或过少。称体重穿的衣服重量要一致，换季更换衣物要评估重量差并告知医生。
7.有跌倒、外伤等身体有出血状况时要及时告知医生或护士。
8.备好止血绷带、点心、体温计、需配药清单或药盒，同时病历本和医保卡请随身携带。
9.服用降压药、降糖药患者，应在透析前遵医嘱停用或减量，避免透析中低血压、低血糖的发生，如已服用请告知医护人员。
10.当日透析前不服大黄、潘泻叶等泻下排便药。

## 透析中要注意什么：

透析中注意血透管路摆放与固定，内瘘患者瘘侧肢体按规定摆放，勿侧卧位，深静脉置管患者管路固定衣服上，体位改变时要注意，勿随意翻身、牵拉，必要时请护士给予协助。
内瘘侧肢体暴露在外时注意保暖，如感到穿刺部位疼痛或出现其他异常情况，应立即向护理人员或医生反映。
透析中尽量减少进食，如有饥饿感可进食少量点心，如面包、馒头、巧克力等，注意防止窒息。
4、服从医护人员的安排，透析中出现任何不适或原有症状加剧，请立即告知医护人员。
5、穿刺的手臂不能大动或弯曲 ，翻身时不要大幅度牵扯透析管路。

## 透析后注意事项：

1、回血后包扎止血绷带以能扪及震颤又能止血为度，一般压迫时间5~10分钟松开，30分钟后全部解开，注意观察有无出血情况或血肿形成，若无出血、渗血现象，可拿掉纱布以减少对动静脉瘘管的压迫。

### 2、下面介绍内瘘出血的紧急处理方法：

(1)局部压迫止血，注意局部压迫应包括皮肤穿刺点及该穿刺点以上
2cm的位置(血管穿刺点)，压迫力度为血液能通过，既能摸到血管震颤又无出血为标准，一般压迫10min左右。
(2)压迫的同时抬高内瘘侧肢体。
(3)必要时瘘口压迫止血，再重新包扎，注意不能长时间压迫瘘口，以免内瘘血栓形成。
3、如局部有血肿出现，透析当天应立即冰敷，如无假性动脉瘤形成则24h 后可热敷以促进局部血液循环，帮助消肿。
4、回血后待血压稳定缓慢起床，穿衣时注意止血绷带固定妥当，防止移位导致穿刺处出血。
5、回血后如有不适症状应及时告知医务人员，待血压稳定后方可离开透析中心，年老体弱、行动不便者由家属接回。
6、透析结束后整理用物，请勿遗漏个人物品。
7、透析间期如出现口舌发麻、四肢乏力、胸闷、气急等情况，及时来院就诊或电话咨询。
8、按要求松解止血带，关注内瘘震颤情况，有异常及时就医。
9、透析当天24小时内保持穿刺部位干燥 ，勿浸湿 ；置管肾友保持置管口干燥。
