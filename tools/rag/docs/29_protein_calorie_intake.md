# 蛋白质、热量的摄入原则

蛋白质的摄入
研究发现，充足的蛋白质可以增加抵抗力，减少感染的机会，提高存活率。但血液透析会导致额外蛋白质丢失，所以对血液透析患者蛋白质的需要量比未进行透析时要多，蛋白质摄入量每天每公斤1到1.2克，其中优质蛋白质要占百分之50以上，优质蛋白质的来源主要有牛奶、鸡蛋和瘦肉类等。
热量的摄入
热量的摄入必须充足，热量来源百分之60来自碳水化合物，百分之30来自脂肪，百分之10来自蛋白质。一般成年人每天每公斤30到35卡， 儿童高于每天每公斤25卡，60岁以上病人每天每公斤30卡，肥胖者减少热量摄入。含热能高而含蛋白质相对低的食品有土豆、白薯、山药、芋头、藕、荸荠、南瓜、粉丝等。进食量减少时，可适当增加一些食糖或花生油以增加热能满足身体需要。
脂肪的摄入
百分之三十的热量来自脂肪，脂肪摄入量为每天40到60g，烹饪油以植物油为主，以每天不超过20毫升为宜。胆固醇需少于每天300毫克。每3到6个月检测血胆固醇、甘油三脂，每年检查一次低密度脂蛋白与高密度脂蛋白。
